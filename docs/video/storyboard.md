# TopoMaroc GIS — Vidéo de présentation

Source unique : *TopoMaroc-GIS-manuel-utilisation.pdf* (v1.4.0, 24 pages, 46 figures). Aucune fonctionnalité hors manuel. Aucun lien ni adresse de l'application à l'écran ou dans la narration.

## 1. Analyse du document

| Élément | Contenu retenu |
|---|---|
| Objectif | Topographie de terrain au Maroc sur téléphone : coordonnées marocaines, navigation GPS, levés, superficies, partage foncier, exports. |
| Cible | Topographes, géomètres, techniciens, agriculteurs et propriétaires qui travaillent sur le terrain. |
| Atouts | Projection Lambert choisie automatiquement selon la zone ; fonctionne hors connexion ; données sur l'appareil ; calculs exacts (Gauss + géodésique) ; partage à superficie exacte ; rapports PDF ; exports SIG/DAO. |
| Parcours clés | Retrouver une borne (Aller à un point) → lever des points → créer une parcelle → la partager → exporter / éditer le rapport. |
| Limites à respecter | GPS de téléphone : précision métrique, non cadastrale. Partage : proposition technique sans valeur juridique. Données de démonstration fictives. |
| Identité | Bleu marine #0F3D5E, bleu #14527C, orange #D6602A, orange clair #F3A679, fond clair #EEF2F6 ; logo (cible orange dans un losange) ; typographie sans empattement (Inter). |

**Stratégie de production** : captures réelles du manuel présentées dans des maquettes de téléphone animées (travellings, zooms sur la zone utile, surlignages orange), titres cinétiques courts, voix off française, sous-titres synchronisés, musique électronique douce. HeyGen HyperFrames pour la composition, la voix et le rendu MP4 1920×1080 ; déclinaison verticale 9:16 (≈ 60 s) pour les réseaux sociaux.
